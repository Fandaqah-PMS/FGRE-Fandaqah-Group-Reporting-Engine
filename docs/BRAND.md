# Fandaqah brand: FGRE usage

Source: *Fandaqah Identity Guide*.

> The identity guide shows color swatches but **no hex codes**. The values below were sampled from the
> PDF and are approximate. Replace them with the official codes from the design team (or the PMS
> Tailwind config) when available.

## Colors

| Token | Role | Hex (sampled) |
|---|---|---|
| `coral` | Primary / brand accent, logo mark | `#F15F5A` |
| `navy` | Primary text, dark surfaces, logo wordmark | `#252D43` |
| `ivory` | Page background (light) | `#F7F7F3` |
| `slate` | Secondary text, muted UI | `#8A9593` |
| `peach` | Soft accent, highlights | `#FAC6A8` |

Pattern palette (also usable as chart series colors): `teal #224F60`, `ice #B8DADB`,
`salmon #F48A86`, `peach #FAC6A8`.

## Typography (all on Google Fonts)

| Use | Font | Weights |
|---|---|---|
| Titles / headings (EN) | **El Messiri** | 400, 500, 700 |
| Body (EN) | **Montserrat** | 400, 500, 700 |
| Arabic (all) | **Almarai** | 300, 400, 700 |

## Logo

- Bilingual lockup (Arabic + "fandaqah" + coral mark).
- Light backgrounds: navy wordmark. Navy backgrounds: white wordmark. Coral backgrounds: all white.
- Clearspace: at least the width of the "f" on every side.
- Minimum size: 20 px tall (digital), 0.75 mm (print).
- Logo files (SVG) are still needed from the design team → `public/brand/`.
